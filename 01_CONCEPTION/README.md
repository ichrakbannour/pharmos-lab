## Règle de lecture

La v1.2.1 est la version consolidée la plus récente retrouvée dans les sources actuellement accessibles, mais elle précède les décisions stock P81–P91 de novembre. Elle est archivée ici comme source de référence historique, **pas déclarée automatiquement comme dossier actif**.

Avant de la promouvoir comme conception active, il faut :
1. réconcilier ses règles avec la matrice D1–D86 v1.3.3 ;
2. intégrer les décisions PO et addenda P81–P91, notamment les règles stock ;
3. réintégrer les versions sources EXT03 v1.1 et EXT06 v1.1, puis réconcilier EXT02–EXT06 ;
4. faire trancher les contradictions et points ouverts restants par le PO.

Aucune version de ce dossier n'autorise à elle seule un développement, une migration ou un déploiement.
