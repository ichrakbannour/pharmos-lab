## Gouvernance documentaire
Les décisions PO confirmées prévalent sur les propositions et les versions historiques. Une autorisation métier, un GO conditionnel ou un rapport de préparation ne valent pas autorisation d'exécuter une migration, un déploiement ou une intervention système. Les sources doivent être publiées et vérifiées avant d'être considérées comme intégrées au dépôt.
