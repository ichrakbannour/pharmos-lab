## Gouvernance documentaire
Les décisions PO confirmées prévalent sur les propositions et les versions historiques. Un GO conditionnel ou un rapport de préparation ne vaut pas autorisation hors de son périmètre explicite. Aucun GO P0 ne se déduit du GO conditionnel STOCK P88. Aucune migration, aucun déploiement ni aucune intervention système ne sont autorisés par un simple rapport d'audit.

**Statut GO P0 (27/11/2026)** : orientation conditionnelle uniquement ; P0 non autorisé ; C-01 à C-08 non remplies. Le GO conditionnel STOCK P88 est distinct et ne vaut pas GO P0. [Addendum de suivi](03_RAPPORTS_AUDIT/ADDENDUM_SUIVI_GO_P0_20261127.md).
